免激活的官方 Win11 企业版虚拟机镜像

微软 Windows 11 企业版虚拟机镜像叫做“Windows 11 Development Environment”(WDE) 翻译过来就是“Win11 开发环境”，实际上它是微软官方为开发者们提供开发和测试用的，在有效期内使用是完全免费而且免激活的。当然，我们普通用户也能随意下载来玩一玩！

微软目前为四种主流虚拟机软件打包好了镜像，包括：VMWare、Hyper-V (Gen2)、VirtualBox 和 Parallels Desktop (Mac)。你下载之后，只需导入到这些虚拟机软件里，即可立即运行，而不必等待漫长的安装过程！使用上非常简单，比手工下载 Windows 11 镜像去安装还要容易。

这些虚拟机可以在有效期内免费免激活使用，大概有 90 天有效期 (以你下载到的包的限期描述为准)，如果版本到期的话，桌面背景会变成黑色并且会有桌面通知。届时你只需要重新下载更新版本的虚拟机包即可继续使用。

正因如此，WDE 虚拟机镜像虽然无需激活，但也只是更加适合用于“测试”、“开发”等用途，而非长期办公使用。有需求的朋友还是可以收藏备用的。

评估虚拟机包含的内容：

  • Windows 11 企业版（评估版）
  • Visual Studio 2022 社区版
  • 启用了 WSL 2 (Windows Linux 子系统)，并安装了 Ubuntu
  • 安装了 Windows 终端
  • 开发者模式已启用

Win11 虚拟机使用方法：

  • 根据你所使用的虚拟机软件，下载对应的 Windows 11 虚拟机版本
  • 下载完 ZIP 文件并解压后，会得到名为 WDE.vhdx 的文件(不同虚拟机对应的文件名扩展名不同)，这就是虚拟机的虚拟硬盘文件
  • 以 VMWare 或者 VirtualBox 虚拟机为例，新建一个虚拟机，然后把 WDE.vhdx 作为虚拟硬盘添加进去即可。
  • 启动虚拟机，并按照屏幕上的引导简单设置一下，就能轻松进入 Windows11 的桌面了

Windows 11 虚拟机常见问题：

虚拟机的要求是什么？

虚拟机需要至少 8GB 的内存和至少 70GB 的磁盘空间。

这些虚拟机的用户密码是什么？

默认用户帐户没有设置密码。但是有些软件，比如远程桌面连接，可能需要你先为系统用户帐户设置密码，然后才能使用该软件。

是否可以长期使用这些映像中的 Windows 许可证？

不，这些虚拟机映像使用的是 Windows 企业评估版，不支持使用产品密钥进行激活。过期后需要重新下载新的版本映像。

是否可以获取 ARM 版本的虚拟机？

目前没有提供 ARM 版本。因此 Parallels Desktop 虚拟机镜像仅支持 Intel 机型。在 M 系列芯片的 Mac 上无法使用， 目前你只能手工下载 Win11 ARM 镜像安装使用。

我在 VirtualBox 上时遇到一些奇怪的渲染问题？

是的，我们注意到在 VirtualBox 上运行这些开发者镜像时会存在一些渲染问题。开始菜单可能看起来与预期不同。我们目前正在调查这种行为，日后会更新，感谢您的耐心和理解。
