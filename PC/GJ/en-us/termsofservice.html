II. Service Rules

1. Contents of this Service

The content of this Service includes:

- Health checkup: One-click quick checkup of your computer's health status, including system useless file cleanup, identifying and detecting risky system problems. Give optimization suggestion.

- Deep Cleanup: Comprehensively scan your computer system to clean up junk files such as useless files, browser and application caches to maximize the release of storage space and improve system performance.

- One Click Acceleration: Easily clean up temporary system files, release and optimize system memory usage to improve computer operation efficiency and free up space.

- Windows Update: Securely transfer real updates to your device, maintaining sound, vision, Internet connectivity, and essential hardware components such as mouse and keyboard.

- Virus and Threat Protection: Performs comprehensive system scanning with Windows Security Center to detect and isolate potential risks in a timely manner.

- Reset Default Apps: Helps restore the default state of Windows apps and improve the efficiency of app operation.

- Taskbar Repair: Repair the native Windows taskbar with one click and restore the default taskbar interface.

- Disk Analysis: Analyze disk space usage and provide detailed space usage suggestions by file types.

- Space Management: Quickly clean up system useless files, browser cache, application cache and other junk files, help identify files that take up a lot of space, download files and duplicate files, free up disk space.

- Process Management: Quickly close useless application processes to optimize performance and reduce resource consumption.

- Startup Item Management: Manage items running at Windows startup to improve system startup speed.

- Application Uninstallation: Easily uninstall most of the applications, limit the applications that Windows allows to uninstall.

- Toolbox and Gadgets: Integrate a variety of Windows utilities and quick access to utility URL functions.

- Intelligent Acceleration: Automatically cleans up the system's temporary files and memory when the temporary files reach 1GB, ensuring that the system stays running efficiently.

4. Access to User Data

When you use Microsoft Computer Manager to clean up your PC (deep cleanup, health checkup, intelligent acceleration, disk analysis), depending on the features used, the following data may be accessed on your system to make cleanup recommendations to you and to delete files you choose to delete:

- Cookies or data from websites you visit;

- Records of content you have downloaded from websites;

- Files on your device;

- Windows user profile names;

- Windows system registry entries;

- Windows system update files.

This data is processed on your device and is not sent to our server. Microsoft PC Manager will not read the contents of the files or any personal user information.

When you use Microsoft PC Manager to manage your app pop-ups, we will only block the advertisement pop-ups of the apps that you choose to block (including manual blocking), and this function will only be processed on your device, and will not send the information of the blocked pop-ups to our server.

If you choose to join the Microsoft pop-up management program, you can take screenshots of pop-ups you don't want to see but can't close and send the screenshots to us to help us optimize the pop-up management feature of Microsoft PC Manager. In this program, we will not collect any information other than the screenshots you send us. Even after participating in this program, you can opt out of the Microsoft PC Manager pop-up management program through [Settings].

When you use Microsoft Computer Manager to manage applications and services on your PC (running a  health checkup, process management, startup item management, application uninstallation, taskbar repair, resetting default applications, using toolboxes and gadgets), the following data may be processed locally on your system, depending on the features used:

- Installed browsers and related settings.

- Installed applications.

- Application startup items/process items/services and scheduled tasks.

This data is processed on your device and is not sent to our server.
