💡 DNS 配置使用指导

🪟 Windows 系统配置

  1. 按 Win + R 打开运行，输入 ncpa.cpl 并回车。
  2. 右键点击正在使用的网络适配器，选择“属性”。
  3. 双击“Internet 协议版本 4 (TCP/IPv4)”。
  4. 勾选“使用下面的 DNS 服务器地址”，填入首选与备用 IP。
  5. 点击确定保存，并在 cmd 执行
    清除系统DNS缓存: ipconfig /flushdns 。

🍎 macOS 系统配置

  1. 打开“系统设置” -> “网络”。
  2. 选择当前连接的网络（Wi-Fi 或以太网），点击“详细信息”。
  3. 切换到“DNS”标签页。
  4. 点击左下角“+”号添加自定义 DNS 服务器 IP。
  5. 点击“确定”并应用修改。

📱 Android / iOS 移动端

  1. iOS：设置 -> Wi-Fi -> 点击网络旁的(i) -> 配置 DNS -> 改为“手动”并添加 IP。
  2. Android：设置 -> 连接与共享 -> 私有 DNS -> 输入 DoH 域名主机名 , 例如 :
    dns.alidns.com
