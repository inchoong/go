自我恢复

与许多在应用程序中储存经常过期的位址清单的 VPN 不同，nthLink 行动应用程序即使在很长时间未使用后也可以连接到网路。

nthLink 应用程序根据您所在的位置和您使用的装置会计算新的伺服器位址，让您即使在许多位址被封锁的位置也能进行连线。它会不断尝试，直到为您找到安全连线。

网络运行状况

nthLink 的先进入侵侦测系统可保护其网路和伺服器免受多种网路威胁

nthLink的可扩展设计可动态调整系统资源以达到最佳使用率，确保最佳的使用者体验。

卓越的反审查技术

nthLink 采用先进技术设计与开发：

  • 透过安全隧道 (VPN) 上网
  • 使用自动 IP 切换来隐藏您的位置
  • 使用可信任的 DNS 服务隐藏您所浏览的网站地址
  • 透过网路混淆技术隐藏您的线上活动
  • 使用 TLS, AES-128, Chacha20-Poly1305 等加密法保護你的信息傳輸

nthLink 与 Tor 有什么不同？

类似于 Tor 网络，nthLink 透过私密和匿名的方式访问互联网。与 Tor 不同的是，nthLink 流量不会多次连结地址之后才抵达预期目的地。这表示 nthLink 比 Tor 更快。这也意味着，相对于 Tor，nthLink 理论上可获取更多流量相关的数据，但nthLink 并不跟踪这些数据。请留意，Tor 流量可受到检查，并且更容易被屏蔽。

如何安全下载此应用？

可通过检查文件的签名对下载进行验证。请前往下载页面查看相关信息。

nthLink 收集哪些数据？

nthLink 仅收集可靠服务所需的极少数据，例如 IP 地址、设备类型和操作系统。nthLink 不收集任何个人可识别信息或浏览历史。

nthLink 无法正常运行。我该怎么办？

首先，请从可靠来源下载最新版 nthLink。相关详细信息，请访问下载页面。如果仍然无法使用，请通过应用中的反馈表单提交报告，也可以发送电子邮件至 [email protected]。
