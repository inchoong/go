Windows 11 右下角显示「下午 19:10:15」（24小时制、上午/下午+时:分:秒）

目标效果：下午 19:10:15（还带跳动秒数），和截图样式一致。
⚠️Win11任务栏默认短时间格式不支持秒，要实现秒，需要两步：修改区域时间格式 + 注册表开启任务栏秒显示。

第一步：修改区域时间格式（显示「上午/下午」）

  1. Win+i 打开设置 → 时间和语言 → 语言和区域（或者 Win +R 运行：timedate.cpl ）
  2. 找到「区域格式」→ 点击 更改格式
  3. 点击最下方：其他设置（日历）
  4. 切换到【时间】标签页：
    • 短时间：填写：tt h:mm:ss
    • 长时间：填写：tt h:mm:ss

      tt = 上午/下午；h=12小时制；H=24小时制；mm分；ss秒

  5. 点击【应用】→【确定】。

如果你想要 下午 19:10:15,2026‑09‑29,周二（连同日期星期全部显示在右下角）

  • 切换到【日期】标签页，短日期填入：yyyy‑MM‑dd,ddd

第二步：注册表开启任务栏显示跳动秒数（Win11关键）

Windows11新版（22H2及以后）任务栏默认不会显示秒，必须注册表开启开关 ShowSecondsInSystemClock。

  1. 按 Win+R，输入 regedit 回车打开注册表编辑器
  2. 定位路径：
计算机\HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
  1. 在右侧空白右键 → 新建 → DWORD(32位)值
  2. 命名：ShowSecondsInSystemClock
  3. 双击这个新建项，数值数据填: 1 ，基数十进制，确定。

第三步：让设置立刻生效

方法A：重启电脑。
方法B（不用重启）：

  1. Ctrl+Shift+Esc打开任务管理器
  2. 找到 Windows资源管理器，右键「重新启动」。

格式参数对照表（你可以自由微调）

格式代码 含义
tt 显示中文「上午 / 下午」
h 12小时制小时（1‑12）
HH 24小时制小时（0‑23）
mm 分钟
ss 秒
yyyy‑MM‑dd 年‑月‑日
ddd 星期（周一、周二）

你截图完整样式：下午 19:10:15,2026‑09‑29,周二

  • 短时间：tt h:mm
  • 短日期：yyyy‑MM‑dd,ddd

    要带上秒：短时间写 tt hh:mm:ss

故障排查

  1. 修改完右下角没有出现秒：确认注册表值ShowSecondsInSystemClock=1，重启资源管理器；Win11旧版本不支持。
  2. 显示 AM/PM英文而不是中文上午下午：控制面板→时钟和区域，系统区域设置为【中文(中国)】。
  3. 任务栏空间不够，时间被截断：把任务栏调宽一点，或者缩小任务栏图标。

一键reg脚本（复制保存，双击导入，懒人用）

新建文本文档，粘贴下面内容，保存为 启用任务栏显示秒.reg，编码选ANSI，双击导入注册表。

Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced]
"ShowSecondsInSystemClock"=dword:00000001

导入完成重启资源管理器即可。

注意：部分Win11版本任务栏宽度有限，如果格式写的太长（时间+完整日期星期），任务栏会显示不全，建议酌情取舍。
